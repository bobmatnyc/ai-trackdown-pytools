# Fix GitHub CLI --json flag error in create_issue and create_pr methods

## Description
## Problem
The GitHub sync functionality is failing because the `create_issue` and `create_pr` methods in `/Users/masa/Projects/managed/ai-trackdown-pytools/src/ai_trackdown_pytools/utils/github.py` are using the `--json` flag with `gh issue create` and `gh pr create` commands, but these CLI commands don't support this flag.

## Error Details
```
Failed to sync TSK-0143: GitHub CLI error: unknown flag: --json
Usage:  gh issue create 
```

## Code Locations
1. **Line 102-103** in `create_issue()` method:
   ```python
   args.append("--json")
   args.append("number,title,url,state,createdAt,id")
   ```

2. **Line 267-268** in `create_pr()` method:
   ```python
   args.append("--json")
   args.append("number,title,url,state,createdAt,id")
   ```

## Solution Options
Choose one of these approaches:

### Option A: Remove --json and Parse Output Differently
- Remove the `--json` flag from both methods
- Parse the default CLI output (usually shows URL and basic info)
- Extract the issue/PR number from the output

### Option B: Use Separate Command to Get Details
- Create the issue/PR without `--json` flag
- Parse the URL or number from the output
- Make a separate `gh issue view <number> --json` or `gh pr view <number> --json` call to get full details

### Option C: Replace with GitHub API Library
- Replace CLI calls with direct GitHub API calls using the `requests` library or GitHub Python library
- This would provide more reliable JSON responses

## Requirements
- Both `create_issue` and `create_pr` methods must return the same Dict structure they currently return
- The returned data should include: number, title, url, state, createdAt, id
- Maintain backward compatibility with existing sync functionality
- Ensure error handling is preserved

## Files to Modify
- `/Users/masa/Projects/managed/ai-trackdown-pytools/src/ai_trackdown_pytools/utils/github.py`

## Testing
After the fix, test that GitHub sync works without the CLI error.
