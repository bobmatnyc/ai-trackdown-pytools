# Research GitHub sync run_in_executor error

## Description
Analyze the GitHub sync codebase to identify where BaseEventLoop.run_in_executor() is being called with incorrect keyword arguments like 'title'. The error shows that 131 items failed to sync because run_in_executor() got unexpected keyword arguments. 

Focus on:
1. Locating all run_in_executor() calls in GitHub sync code
2. Understanding how GitHub API calls are being wrapped for async execution
3. Identifying where item attributes (title, body, labels) are being incorrectly passed as keyword arguments
4. Determining the correct pattern for passing these arguments to GitHub API functions

The run_in_executor() method signature is: run_in_executor(executor, func, *args) - it does NOT accept keyword arguments.
