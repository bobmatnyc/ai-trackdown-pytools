# Ops: Build and publish version 1.5.6 to PyPI

## Description
Build and publish ai-trackdown-pytools version 1.5.6 to PyPI following the deployment procedures outlined in CLAUDE.md.

## Context
- Version has been bumped to 1.5.6 and committed with tag v1.5.6
- This is a patch release fixing run_in_executor() keyword argument error in GitHub and Jira sync adapters
- Version files have already been updated and committed

## Required Tasks
1. Clean any previous build artifacts (dist/, build/, *.egg-info)
2. Build distribution packages using `python -m build`
3. Verify build contents and package structure
4. Upload to PyPI using twine
5. Verify the package is available on PyPI and installable

## Deployment Procedures (from CLAUDE.md)
Follow the mandatory PyPI publishing procedures:
- Pre-publishing requirements are met (version updated, tests passing, documentation updated, git tag created)
- Use the specified build process with `python -m build`
- Verify build contents before publishing
- Upload using `python -m twine upload dist/*`
- Post-publishing verification with installation test

## Success Criteria
- Clean build artifacts removed
- Distribution packages built successfully
- Build contents verified
- Package uploaded to PyPI successfully
- Package installable from PyPI
