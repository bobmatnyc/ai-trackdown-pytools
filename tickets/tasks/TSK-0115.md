# Fix GitHub CLI --json flag error in sync adapter

## Description
Fix the GitHub CLI commands in src/ai_trackdown_pytools/utils/github_utils.py that incorrectly use --json flag with create operations. The issue is in:

1. create_issue() method (lines 102-103): gh issue create --json is invalid
2. create_pr() method (lines 267-268): gh pr create --json is invalid

Both commands need to be split into:
- Create the issue/PR without --json flag
- Extract the number from creation output
- Use separate view command with --json to get details

Pattern should be:
```python
# Create first
result = subprocess.run(['gh', 'issue', 'create', ...], capture_output=True)
# Parse number from URL in output
issue_number = extract_number_from_url(result.stdout)  
# Then get JSON details
json_result = subprocess.run(['gh', 'issue', 'view', issue_number, '--json', 'number,title,url'])
```

Ensure proper error handling and URL parsing for both methods.
