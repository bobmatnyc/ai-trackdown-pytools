# Task: Engineer agent to fix GitHub CLI --json flag error

## Description
**DELEGATION REQUEST FOR ENGINEER AGENT**

**Objective**: Fix GitHub CLI commands that incorrectly use --json flag with create operations

**File to Fix**: `src/ai_trackdown_pytools/utils/github_utils.py`

**Specific Problems**:
1. Line 102-103: `create_issue()` method uses invalid `gh issue create --json number,title,url`
2. Line 267-268: `create_pr()` method uses invalid `gh pr create --json number,title,url`

**Root Cause**: GitHub CLI create commands (`gh issue create` and `gh pr create`) do NOT support the `--json` flag for output formatting.

**Required Solution Pattern**:
```python
# Instead of: gh issue create --json number,title,url (INVALID)
# Use this two-step approach:

# Step 1: Create without --json flag
create_result = subprocess.run(['gh', 'issue', 'create', '--title', title, '--body', body], 
                              capture_output=True, text=True)

# Step 2: Extract issue number from creation output URL
issue_number = extract_number_from_github_url(create_result.stdout.strip())

# Step 3: Get JSON details with separate view command
json_result = subprocess.run(['gh', 'issue', 'view', str(issue_number), '--json', 'number,title,url'], 
                            capture_output=True, text=True)
```

**Implementation Requirements**:
1. Create a helper function `extract_number_from_github_url()` to parse GitHub URLs
2. Update `create_issue()` method to use two-step process
3. Update `create_pr()` method to use two-step process
4. Maintain existing return format and error handling
5. Ensure proper text encoding in subprocess calls

**Expected Outcome**: Both methods successfully create GitHub issues/PRs and return JSON details without CLI flag errors.

**Context**: This is part of the GitHub sync adapter functionality in the AI trackdown tools.
