# Fix GitHub CLI --json flag compatibility issue

## Description
Apply critical fix to GitHub CLI integration in ai-trackdown-pytools. 

**Problem**: The GitHub CLI --json flag is causing errors in both create_issue() and create_pr() methods in `/Users/masa/Projects/managed/ai-trackdown-pytools/src/ai_trackdown_pytools/utils/github.py`.

**Root Cause**: Lines 101-106 (create_issue) and lines 266-271 (create_pr) are incorrectly using --json flag during creation operations.

**Required Fix**:
1. **create_issue() method (lines 101-106)**:
   - Remove --json flag from create command
   - Run create without --json to get output
   - Parse output to extract issue number from URL (regex pattern: `/(\d+)$`)
   - Run secondary command: `gh issue view {number} --json number,title,url,state,createdAt,id`
   - Return JSON from view command

2. **create_pr() method (lines 266-271)**:
   - Remove --json flag from create command  
   - Run create without --json to get output
   - Parse output to extract PR number from URL (regex pattern: `/(\d+)$`)
   - Run secondary command: `gh pr view {number} --json number,title,url,state,createdAt,id`
   - Return JSON from view command

**Implementation Pattern**:
```python
# Create without --json
output = self._run_gh_command(args)
# Parse number from output like "https://github.com/owner/repo/issues/123"
import re
match = re.search(r'/(\d+)$', output.strip())
if match:
    number = match.group(1)
    # Get JSON details
    view_output = self._run_gh_command(['issue', 'view', number, '--json', 'number,title,url,state,createdAt,id'])
    return json.loads(view_output)
```

**Files to Modify**:
- `/Users/masa/Projects/managed/ai-trackdown-pytools/src/ai_trackdown_pytools/utils/github.py`

**Priority**: Critical - this fixes GitHub sync functionality that was broken in version 1.5.7

**Expected Outcome**: Both create_issue() and create_pr() methods should successfully create GitHub resources and return proper JSON responses without CLI compatibility errors.
