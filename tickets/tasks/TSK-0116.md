# Engineer: Fix GitHub CLI --json flag error in sync adapter

## Description
ENGINEER TASK: Fix the GitHub CLI commands in src/ai_trackdown_pytools/utils/github_utils.py

**Problem**: GitHub CLI create commands don't support --json flag
- Line 102-103: create_issue() uses invalid `gh issue create --json`
- Line 267-268: create_pr() uses invalid `gh pr create --json`

**Required Fix**:
1. Split each create operation into two commands:
   - First: Create without --json flag
   - Second: Get details with view command using --json

2. Pattern to implement:
```python
# Create the issue/PR first
result = subprocess.run(['gh', 'issue', 'create', ...], capture_output=True, text=True)
# Parse issue/PR number from creation output URL
number = extract_number_from_url(result.stdout.strip())
# Get JSON details with separate command
json_result = subprocess.run(['gh', 'issue', 'view', str(number), '--json', 'number,title,url'], capture_output=True, text=True)
```

3. Add URL parsing helper function to extract issue/PR numbers from GitHub URLs

**Deliverables**:
- Fix create_issue() method around lines 102-103
- Fix create_pr() method around lines 267-268  
- Add URL parsing utility function
- Ensure proper error handling for both commands
- Test both methods work correctly

**Files to modify**: src/ai_trackdown_pytools/utils/github_utils.py
