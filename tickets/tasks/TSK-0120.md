# QA: Test GitHub sync functionality after CLI --json flag fix

## Description
Comprehensive testing of GitHub sync functionality after Engineer fixed the --json flag error in GitHub CLI commands.

**Context**: Engineer fixed issue where `gh issue create` and `gh pr create` incorrectly used --json flag. The fix involved:
1. Splitting create operations into two steps (create then view with --json)
2. Added URL parsing to extract issue/PR numbers
3. Updated both create_issue() and create_pr() methods in github_utils.py

**Testing Requirements**:
1. **Test Suite Execution**: Run comprehensive test suite to ensure no regressions
2. **GitHub Command Testing**: Verify GitHub sync commands work without --json flag error
3. **Creation Validation**: Test that issues and PRs are created successfully
4. **Data Validation**: Confirm returned JSON contains correct number, title, and url fields
5. **Error Handling**: Test error scenarios and invalid inputs
6. **Integration Testing**: Verify end-to-end GitHub sync workflow

**Files Modified**: 
- src/ai_trackdown_pytools/utils/github_utils.py

**Expected Outcomes**:
- All tests pass without CLI flag errors
- GitHub issues/PRs create successfully
- JSON responses contain required fields
- Error handling works correctly
- No regressions in existing functionality

**Priority**: High - Critical fix needs validation before release
