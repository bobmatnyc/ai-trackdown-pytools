# Add ticket type conversion commands (TSK <--> ISS, ISS <--> EP)

## Description
Implement functionality to convert tickets between different types:

- Convert tasks (TSK) to issues (ISS) and vice versa
- Convert issues (ISS) to epics (EP) and vice versa
- Preserve all metadata, descriptions, and relationships during conversion

Use Cases:
1. Task realized to be larger scope → Convert TSK to ISS
2. Issue realized to be simple task → Convert ISS to TSK  
3. Issue grows to encompass multiple items → Convert ISS to EP
4. Epic simplified to single issue → Convert EP to ISS

Implementation Requirements:
- Add new CLI command: aitrackdown convert <ticket-id> --to <type>
- Preserve ticket content, priority, tags during conversion
- Update parent/child relationships appropriately
- Handle ticket numbering (maintain original or create new based on flag)
- Archive original ticket after conversion
- Update any references in related tickets

Acceptance Criteria:
- Can convert TSK to ISS and ISS to TSK
- Can convert ISS to EP and EP to ISS
- All metadata preserved during conversion
- Original tickets archived with conversion reference
- CLI command with clear syntax and help text
- Unit tests for conversion logic
- Integration tests for CLI command
